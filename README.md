# Revisor PR23 · DTO 90

Descargas de la aplicación **Revisor PR23 · DTO 90** de Aguas Patagonia de Aysén, que revisa los resultados del autocontrol PR23 de las plantas de aguas servidas: calidad contra los límites del DTO 90 y programación mensual.

Este repositorio contiene **solo los ejecutables y sus notas de versión**. El código fuente es privado.

## Descargar

1. Entra a **[Releases → la versión más reciente](https://github.com/Dani-APA/PR23-releases/releases/latest)**.
2. En "Assets", descarga `Revisor_PR23_DTO90_vX.Y.Z.exe`.
3. Guárdalo en una carpeta tuya (por ejemplo, Documentos) y ábrelo con doble clic. No requiere instalar Python ni otros programas.

Requisitos: Windows 10 u 11 de 64 bits.

## Primera vez que lo abres

El ejecutable no tiene firma digital, así que Windows puede mostrar **"Windows protegió su PC"**. Haz clic en **"Más información" → "Ejecutar de todas formas"**. Si el antivirus de la empresa lo bloquea, pide a TI que lo autorice.

## Actualizaciones

Desde la versión **1.6.0**, la aplicación se actualiza sola:

- Al abrirla, revisa si hay una versión nueva; si la hay, el botón de la esquina superior derecha se pone **naranjo** y dice "Actualizar a vX.Y.Z".
- Al aceptar, descarga la versión nueva en la misma carpeta, verifica que el archivo esté íntegro, la abre y borra la anterior.

Si tienes una versión anterior a la 1.6.0, descarga la más reciente una vez desde aquí; después ya no hace falta.

## Consultar QSYS

Para usar el botón **"Consultar QSYS"** necesitas tu propio usuario y clave de QSYS con acceso a *Informes → PR-023 Aguas Servidas*. La clave no se guarda nunca. Sin usuario de QSYS puedes usar **"Abrir PR23"** con un archivo descargado.
